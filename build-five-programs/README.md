# Build Five Programs

This project was part of the **freeCodeCamp Bash Scripting** curriculum. 
Its goal was to become familiar with basic shell commands and Bash scripting by building five small programs.

### Programs
- `questionnaire.sh` — collects user information.
- `countdown.sh` — counts down to zero.
- `bingo.sh` — runs a simple Bingo program.
- `fortune.sh` — displays a fortune.
- `five.sh` — runs the other four programs.

### Learned skills
- Working with the command line and shell commands.
- Writing and executing Bash scripts.
- Using variables, loops, conditionals, and command-line arguments.
- Combining multiple scripts into one program.
